# Packaging adaptations and boundaries

This is a model-improvement handoff, not the complete repository. It excludes data collection/cleaning scripts, all raw sources except NY weekly claims, the old diagnostics renderer/database, large feature-audit caches, candidate-grid forecasts, duplicate plots, prior test logs, credentials and Git metadata.

The six computational modules (`data_availability`, `rolling_stl`, `feature_engineering`, `rolling_validation`, `run_validation`, `out_of_sample`) are byte-identical to the source project. Two report modules are included because of actual imports; only hard-coded interpreter text `/opt/anaconda3/bin/python3` was replaced by `python`. Their baseline computations are unchanged. The frozen lock hashes the untouched forecasting/feature/STL modules and original specification/metadata files; it is retained without alteration.

`src/handoff.py` is new packaging glue. It rebuilds original-origin features directly from included inputs and calls the existing sampling/forecast/metric functions. It never invokes selection or a candidate grid. For validation it uses the original 2019 label ceiling; for later testing it uses the existing expanding-label adapter. It writes to a new folder and compares every prediction/status to the saved baselines. It bypasses the original launchers' old payroll-audit/cache file dependencies; no historical feature bank is shipped. Do not use the archival launchers as standalone entry points in this minimal package.

The general-purpose `load_raw_inputs` helper in `data_availability.py` describes five optional non-core constituent files from the full repository. Core model loading uses `load_core_inputs`, which needs only the included NY claims file. Non-core data collection and daily-indicator reproduction are intentionally out of scope; adding such indicators requires their own raw constituents and release evidence.

Retained tests preserve baseline assertions. Availability fixtures now load NY claims only; its aggregate-mismatch test covers NY claims only rather than also S&P 500. Removed tests require omitted non-core daily/national-claims inputs, old all-repository preservation manifests, old diagnostics helpers, old audit snapshots, or the omitted historical feature cache. These are scope omissions, not skipped failures; no retained test is silently skipped. A new handoff integrity suite replaces full-repository preservation checks with included-file hashes, metrics, import and path checks. The precise removed method names and copied-file source hashes are recorded in `provenance/source_manifest.json`.

`FILE_INVENTORY.csv` lists each included file and its purpose; it excludes its own digest to avoid self-reference. Canonical CSVs and PNGs are copied byte-for-byte. A small derived `coverage_summary.csv` makes the retained coverage definitions explicit without duplicating forecast rows. `results/reproduced/` is not shipped: it is generated and checked only in an isolated copy. The ZIP contains one project root, the same files as the final handoff folder, and no virtual environment, caches, temporary logs or symlinks.
