# Verification and reproducibility

**Ready to share with the methodological caveats in MODEL_RESULTS.md.** No new model experiment or selection was performed.

- **Tests:** 73 passed, zero skipped: 68 retained baseline tests plus five handoff integrity/import/metric tests. Executed both inside the final handoff folder and inside an isolated package copy. Eleven tests from the full 79-test project suite depend on intentionally omitted non-core inputs, diagnostics or archival preservation/cache files; they were removed explicitly and listed in `provenance/source_manifest.json`, rather than silently skipped.
- **Dependencies:** Python 3.12.2 and pinned requirements were checked in a temporary virtual environment with access to the installed system site-packages. `python -m pip install --no-index -r requirements.txt` succeeded using those already-installed versions. The same requirements were also checked with `PIP_NO_INDEX=1 python -m pip install -r requirements.txt`. This verifies the available dependency closure; **a fresh network installation in a fully empty environment was not performed**. Python 3.12 is the reference version; no API libraries or credentials are required.
- **Saved-result check:** all 12 validation and 72 test metric rows reconcile to their canonical forecasts. Documented tables match the original full-project metrics at their displayed precision. Frozen selections and source hashes match; all included canonical CSVs and PNGs are unchanged copies.
- **Full standalone refit:** in an isolated copy, ran `python tools/run_isolated.py reproduce --output results/reproduced`. Rebuilt **439 original-origin feature windows** from the included panel and weekly NY claims, then refitted **576 selected validation forecasts + 960 frozen test forecasts**, with no candidate grid or model-selection call. All forecast statuses and predictions match the saved results: largest absolute difference **4.44e-16 pp** for validation and **6.40e-14 pp** for tests. Reproduced metrics also match (tolerance 1e-10). The runner checks predictions at absolute tolerance 1e-6 pp plus relative tolerance 1e-8; the observed differences are much smaller. The runner's SHA256 and machine-readable checks are in `verification_checks.json`.
- **Isolation:** the audit-hook harness disabled network connections and blocked any file read outside the package except installed Python runtime libraries and permitted system timezone resources. No original-project data/code read succeeded. Two nonessential OS version/timezone probes were blocked before reading; computation and tests completed. Temporary files and plotting configuration were confined to the isolated copy's `.runtime/` directory. Runtime libraries themselves necessarily live outside the project; no self-contained Python interpreter is bundled.
- **Portability:** all model/data paths resolve from the package root. No personal absolute paths, API clients, credentials, environment-secret files, symlinks, Git metadata, caches, virtual environments or generated reproduction folders are shipped. Original legacy main programs still refer to omitted archival caches: use the documented portable runner, which reuses their forecasting/eligibility functions. The optional five-source general raw-loader is not the core entry point; see PACKAGING_NOTES.
- **Original preservation:** all **201 non-secret, non-cache files** in the original full project retain their pre-packaging SHA256 hashes, and that file set is unchanged. No original file was created, modified, moved or deleted. Credential files and hidden Git/configuration data were never read for packaging or copied. No commit, push or GitHub operation occurred.
- **Share archive:** the ZIP is checked against every included file byte-for-byte and has exactly one project root. `FILE_INVENTORY.csv` explains each included file and records its SHA256; it excludes itself to avoid self-reference.

For a quick check, run `python -m src.handoff inspect`. To repeat guarded testing, run `python tools/run_isolated.py tests`; to display features, run `python -m src.handoff features --origin 2023-12-31`. The normal retained-suite command is `python -m unittest discover -s tests -v`.

Reproduction is a refit of historical fixed baselines, not a claim of historical numerical-vintage accuracy. It does not reproduce data fetching/cleaning, the full candidate-grid search, or every prior diagnostic artifact. Numerical optimizer behavior may differ slightly on other numerical-library/CPU builds; the pinned reference stack and per-forecast reconciliation make those differences visible rather than concealing them. No project input or model dependency is missing for the documented core reproduction path.
